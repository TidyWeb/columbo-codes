The central idea

Code is the final description—not the first thought

Many beginner exercises look like punctuation problems: where does the colon go, how far should this line be indented, and which else belongs to which if? Usually, the real difficulty appeared earlier. The rules have not yet been separated, ranked and arranged into understandable units.

The goal is not to “think in Python” immediately. The goal is to investigate clearly enough that Python has something orderly to describe.

The Columbo Codes principle
The detective method

See the decision world before entering it

Every case begins in ordinary language. The method turns that story into a mental map before it introduces Python-shaped structure.

01

Collect the facts

What can change from one situation to the next? Name every state, category and boundary.

02

Classify their jobs

Does a fact override ordinary rules, select an ordinary result, or modify an eligible result afterwards?

03

Rank the questions

Which rule controls the widest part of the remaining decision world? Stronger rules must be asked first.

04

Build decision units

An if / elif / else chain works from top to bottom. The first true branch wins that chain.

05

Follow the value

Different routes can establish one shared value, rejoin, and hand that result to the next operation.

06

Translate the plan

Indentation records ownership: which instructions belong to which question and which world they operate inside.

How to use this casebook

Do not race to the answer

  1. Read the story first.Make sure you understand the world before looking for Python.
  2. Pause at each governing question.Try to predict which route should open and why.
  3. Use the silhouettes as maps.They reveal the shape without handing you a completed program.
  4. Return with another puzzle.The method becomes useful through repetition across different criteria.
The casebook will grow

Every new exercise brings different facts. The investigation stays the same: discover what can change, determine which rules have the widest effect, and make the structure visible before asking Python to run it.

Practice does not merely make perfect. It makes the clues easier to recognise.
